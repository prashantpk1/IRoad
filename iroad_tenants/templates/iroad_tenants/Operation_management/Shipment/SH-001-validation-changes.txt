--- 2. iroad_tenants/views.py ---

New functions:

  _tenant_shipment_has_active_duplicate()   -> block second shipment per line
  _tenant_shipment_validate_submission()    -> all matched-field rules

Booking options:
  - Dropdown lists only booking_status = Confirmed (not Draft/Cancelled)

Create & Edit POST:
  - Full validation before save; errors shown via form_errors + messages
  - order_type, pod_type, pod_doc_count from matched booking line (not tampered)
  - collection_status = Pending on create
  - trip_type saved from booking

Server validation rules:
  - Client account required and active
  - Booking required, Confirmed, belongs to client
  - Booking item + type required; must match booking line
  - No duplicate active shipment (same booking + booking_item_type)
  - Shipment date required
  - Loading + delivery address required; must belong to client
  - Cargo required; qty > 0; weight >= 0
  - COD: cod_amount > 0
  - Truck + driver on booking line; both Active
  - Sourcing/truck integrity via model clean()
